# Community Code of Conduct

We want technical disagreement to remain rigorous, useful and respectful.

Contributors and maintainers are expected to:

- discuss code, evidence and trade-offs rather than attacking people;
- welcome questions from people with different Scala, ZIO or agent experience;
- disclose conflicts of interest and security concerns responsibly;
- avoid harassment, discrimination, threats, doxxing and publication of private information;
- accept maintainer decisions on project scope while remaining free to propose alternatives.

Unacceptable behavior may result in content removal or temporary/permanent exclusion from project
spaces. Report conduct concerns privately to the repository owner through GitHub. Reports will be
handled as confidentially as practical.
