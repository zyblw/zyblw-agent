# ADR-0003：工具安全与人工审批

## 背景与问题

模型只能提出工具调用，不能直接执行副作用。提示词不能替代权限、租户隔离和审批。

## 候选方案

1. 工具默认允许，由提示词约束。
2. 仅按工具名称白名单。
3. 默认拒绝，组合 Agent 白名单、scope、风险等级、Guardrail、预算与审批。

## 决定

采用方案 3。工具以类型参数描述输入、错误和输出，异构注册通过受控擦除包装完成。只有明确标记幂等且错误可重试的工具才自动重试。危险调用先持久化 `PendingApproval`，批准后使用稳定 call ID 与幂等键执行。

## 未选择原因

方案 1 无法抵抗 prompt injection；方案 2 不能表达用户/租户权限、结果大小和副作用风险。

## 风险与演化

策略过严可能降低易用性，因此提供显式 policy builder，但安全默认值不变。沙箱是 SPI，不允许 core 直接执行 Shell 或 SQL。
